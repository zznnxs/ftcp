# FTCP: Simplistic Intranet Penetration Service

FTCP 是一个轻量、简单的内网穿透服务项目，旨在通过最简化的流程帮助用户快速实现内网资源的暴露与访问。

---

## 🛠️ 功能特色
- 易于使用：简单的安装与运行，无需繁琐配置。
- 开源免费：项目完全开源，并永久免费。
- 高效稳定：提供高效稳定的内网穿透服务。

---

## 📦 安装与使用

### 环境要求
- 操作系统：支持 Windows、Linux 和 macOS。
- 必需组件：
  - 支持 Go 语言（推荐 v1.18 及以上版本）。

### 快速开始

1. 克隆项目到本地：
```bash
 git clone https://github.com/zznnxs/ftcp.git
```

2. 进入项目目录：
```bash
cd ftcp
```

3. 编译程序：
```bash
go build -o ftcp
```

4. 运行服务：
```bash
./ftcp [参数选项]
```
